                Case study · NAONWORKS · 2022–2026
                
      
                Edge Computing Platform
                
      
                Factory machines speak dozens of protocols. The platform collects their data on site and routes it to databases and clouds. I owned its web console.
                
    
                

    
                
      
                My role
                
      
                I took over the web backend and frontend from the original architect, then maintained and extended nearly every module. I built most of the Vue frontend, with a junior developer contributing.
                
      
                The product began on offline factory networks, so authentication, user management and logging had to be built in. Certification audits require them, and much of that work was mine. I then helped move the product to the cloud.
                
      
                I also ran the team's day-to-day workflow, onboarded new members, led customer demos in English and Indonesian, and started the Node-RED Manager feature.
                
    
                

    

    
                
      
                
        
                Performance on small hardware
                
        
                Non-blocking end to end
                
        
                Edge hardware has little memory to spare. Spring WebFlux, Kotlin coroutines and R2DBC keep every call non-blocking, and BlockHound catches regressions in tests. The service runs on a 192 MB heap.
                
      
                
      
                
        
                Real-time UX
                
        
                One event stream, many screens
                
        
                Dashboards, alarms and session events share one SSE channel. Each screen subscribes only to what it shows, and a force-logout reaches the browser instantly. I extended Chart.js with custom tooltip, legend and center-text plugins for dense traffic data.
                
      
                
      
                
        
                Frontend at scale
                
        
                Forms as data
                
        
                40 protocols and 10 destinations each need a validated form in Korean and English. Forms are generated from typed schemas, and the same rules run on the API, so adding a protocol is a data change.
                
      
                
      
                
        
                Device management
                
        
                The OS, from the browser
                
        
                Operators configure networking, time sync and services through Kotlin wrappers around netplan, ip and systemctl, and manage containers through the Docker Engine API.
                
      
                
    
                

    
                
      
                
        
                On-premise → cloud
                
        
                What each environment requires
                
        
                Moving from offline sites to the cloud meant deciding what to build in and what to hand to managed services. I also containerized the web service for the migration.
                
      
                
      
                
        
                
          
                ConcernOn-premise, no internetCloud
                
          
            
                IdentityBuilt in: accounts, 2FA, lockout, alertsSame controls, audited for CSAP
                
            
                PackagingInstalled directly on the deviceContainer image
                
            
                Transport securityApp serves HTTPSTLS ends at the load balancer
                
            
                SecretsEncrypted on the deviceExternal key management service
                
            
                SessionsIn-memory token store on one nodeShared store or sticky routing
                
            
                DataOne local database with capacity alarmsReplication and failover
                
            
                Audit logsLocal, view-only for adminsDurable central storage
                
            
                IntegrityFile-hash checksImage digests
                
                          
        
                
      
                
    
                

    
                
      
                
        
                Security & certification
                
        
                Built to pass government security review
                
        
                I supported testing for all three programs and wrote the compliance map: which screen, API and class meets each requirement, plus the remaining gaps and fixes.

                KSELSecurity evaluation compliance
                
          
                GSGood Software certification, TTA
